# Final Prompt Assembly Specification (MAS 2 Input)

The `MasContextProvider` service executes the following ordered sequence to build the final prompt string.

---

## 1. Strict Guardrails and Rules
**Source:** `CompiledStoryJson.narrative_context_json.prompt_rules_with_guardrails`

**Data Used:** Direct copy of all combined narrator safety rules and global style rules.
- Examples: “NEVER write player dialogue,” “Maintain a tense mood.”
- **Placed first** to ensure maximum LLM adherence.

---

## 2. Mechanical Status (Tiers 1 and 2)
**Source:** `chimera_game_states.tier1_singular_state` and `tier2_relational_state`

**Transformation:** Serialized into concise factual statements.
- Example: `Player Health: 10/100. Lockpicking Skill: 25.`

---

## 3. Action Result and Sentiment
**Source:** `ActionResolver.OutcomeDto` (Engine result) and `MAS1.Mas1ResponseDto.detectedSentiment`

**Integration:** Direct factual injection.
- Includes action result (Success, Failure, Partial) and emotional context (emotion type + intensity).
- Example: `Outcome: FAILURE. Player sentiment: grudging, intensity 9/10.`

---

## 4. Narrative RAG Context
**Source:** `CompiledStoryJson.narrative_context_json.rag_index` (Vector Search)

**Process:** Retrieval and filtering.
- `MasContextProvider` performs vector search using the **resolvedQuery** generated by MAS 1.
- Inserts top **1–3** most relevant lore/entity chunks only.
- Ensures minimal token use and maximum relevance.

---

## 5. Narrative State (Tier 0)
**Source:** `chimera_game_states.tier0_tracked_state`

**Transformation:** Serialized into narrative memory form.
- Example: `Current relationships: Kiera affinity -10. Recent event: Player insulted guard.`

---

## 6. Call to Action
**Source:** Hardcoded template

Final instruction requesting the LLM to return a `Mas2ResponseDto` JSON structure.

---

# RAG Retrieval Path Details

### MAS 1 → Resolved Query
- The **ActionParser (MAS 1)** converts ambiguous player input into a precise query.
- Example:
  - Raw input: “I talk to her.”
  - Resolved query: “Player talks to Kiera about the slaver camp.”

### MAS 2 → Context Retrieval
- `MasContextProvider` uses the **resolvedQuery** to perform vector search.
- Retrieves only the most relevant lore chunks from the precompiled `rag_index`.
- Produces a **narrow, token-efficient** RAG payload.
