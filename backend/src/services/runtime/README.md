# Runtime Service

**Purpose:** The Game Loop (`mas1`, `engine`, `mas2`)

## Architecture

This service handles the runtime execution of compiled stories:

- **MAS1:** Initial story setup and character initialization
- **Engine:** Core game loop and state management
- **MAS2:** Narrative generation with RAG-powered lore retrieval
