---
description: Test Driven Development
---

When fixing a bug or implementing a specific piece of business logic (backend or frontend), you must follow a test-driven approach. 1. Write a failing test that reproduces the bug or defines the new logic's expected behavior. 2. Run the test and confirm it fails. 3. Write the minimum amount of code required to make the test pass. 4. Refactor the code if necessary, ensuring the test still passes.
