When creating or modifying the gameplay ("play") screen, including its layout, HUD, narrative text rendering, entity links, dossiers, composer, combat state or mobile sheets, follow the approved redesign in `docs/design/play-redesign/`. Read `SPEC.md` first, use the PNGs in `boards/` for layout and tone, and take colours, type and sizing from `tokens.css` rather than hardcoding values. Build in the order given in `ROADMAP.md`. Names and numbers in the boards are sample data and must not be hardcoded. If the spec conflicts with the current code or another rule, report the conflict instead of choosing silently.
